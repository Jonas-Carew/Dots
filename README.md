# Timezone

## System timezone

Go to `/bedrock/run` and relink `localtime`. To do this, run `sudo ln -sf /usr/share/zoneinfo/<Your timezone> ./localtime`.

## Waybar

Go to `waybar/config`. Change the `timezone` field of `clock` to the desired timezone.
